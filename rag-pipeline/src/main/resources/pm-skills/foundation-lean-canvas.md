# 린 캔버스 (Lean Canvas)

**목적**: 비즈니스 모델의 핵심 요소를 한 페이지로 압축하여 가설을 검증한다.

**9개 블록**:
1. **문제(Problem)**: 해결할 상위 3가지 문제. 현재 대안(경쟁사)도 명시.
2. **고객 세그먼트(Customer Segments)**: 초기 타겟 고객 + 얼리어답터 정의.
3. **고유 가치 제안(UVP)**: "우리 서비스만이 제공할 수 있는 것" 한 문장으로.
4. **솔루션(Solution)**: 각 문제에 대한 솔루션 3가지.
5. **채널(Channels)**: 고객 도달 경로 (온라인 마케팅, 파트너십 등).
6. **수익 구조(Revenue Streams)**: 수익 모델 (SaaS, 수수료, 광고 등).
7. **비용 구조(Cost Structure)**: 주요 비용 항목.
8. **핵심 지표(Key Metrics)**: 제품 성공 여부를 판단하는 핵심 수치 3개.
9. **경쟁 우위(Unfair Advantage)**: 쉽게 복사되지 않는 경쟁 우위.

**작성 순서**: 문제 → 고객 → UVP → 솔루션 → 채널 → 수익 → 비용 → 지표 → 경쟁우위

**검증 포인트**:
- 문제가 실제로 고객이 돈을 낼 만큼 중요한가?
- UVP가 경쟁사와 명확히 차별화되는가?
