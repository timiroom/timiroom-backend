# 사용자 여정 맵 (User Journey Map)

**목적**: 사용자가 서비스를 인지하고 이탈하기까지의 전체 경험을 시각화하여 페인포인트와 개선 기회를 발견한다.

**여정 단계**:
1. **인지(Awareness)**: 서비스 최초 인지 경로 (검색, SNS, 추천 등)
2. **고려(Consideration)**: 대안 비교 및 평가
3. **획득(Acquisition)**: 회원가입 또는 첫 구매
4. **온보딩(Onboarding)**: 핵심 기능 첫 사용 경험
5. **활성화(Activation)**: Aha Moment 달성 (서비스 가치 체감)
6. **유지(Retention)**: 반복 사용 및 습관 형성
7. **추천(Referral)**: 지인 공유 및 바이럴

**각 단계 분석 요소**:
- 사용자 행동 (What they do)
- 사용자 생각 (What they think)
- 감정 (Frustrated / Neutral / Delighted)
- 페인포인트 (현재 불편한 점)
- 기회 (개선 가능한 지점)

**여정 맵 작성 규칙**:
- 8단계 이상 세분화
- 각 단계: "사용자 행동 → 시스템 반응 → 다음 단계 연결" 구조
- 80자 이상 서술
- 이탈 발생 지점 명시적 표시
