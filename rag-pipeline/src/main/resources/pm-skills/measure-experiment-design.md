# 실험 설계 (Experiment Design / A/B Test)

**목적**: 가설을 데이터로 검증하는 통계적으로 유효한 실험을 설계한다.

**실험 설계 프로세스**:
1. **가설 정의**: "B를 하면 A가 X% 향상될 것이다"
2. **성공 지표 설정**: Primary Metric (단 1개), Guardrail Metrics (지켜야 할 지표)
3. **샘플 사이즈 계산**: 통계적 유의성 확보를 위한 최소 참여자 수
   - 통상 95% 신뢰수준 (α=0.05), 80% 검정력 (β=0.20)
4. **실험 기간**: 최소 1주일 (요일 효과 상쇄), 권장 2~4주
5. **트래픽 분배**: Control(A) vs Treatment(B), 50:50 권장
6. **롤아웃 계획**: 1% → 5% → 20% → 50% → 100%

**실험 중 모니터링**:
- 샘플 비율 불균형 없는지 확인
- Novelty Effect (초기 과대 반응) 고려
- 조기 종료 금지 — p-hacking 주의

**결과 해석**:
- p-value < 0.05: 통계적 유의미 (단, 실용적 유의미성도 확인)
- 효과 크기(Effect Size): 실제 비즈니스 임팩트 계산
- 세그먼트별 분석: 특정 사용자 그룹에만 효과가 있는가?

**실험 실패 시**:
- 가설이 틀렸는가, 실험 설계가 틀렸는가 구분
- 학습 내용 문서화 후 다음 실험 설계에 반영
