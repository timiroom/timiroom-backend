# OKR 작성 (Objectives & Key Results)

**목적**: 조직의 목표를 명확히 하고 측정 가능한 결과 지표로 연결한다.

**OKR 구조**:
- **Objective (O)**: 정성적, 영감을 주는 목표 ("무엇을 달성할 것인가")
- **Key Results (KR)**: 정량적, 측정 가능한 결과 ("어떻게 알 수 있는가") — 3~5개

**좋은 Objective 조건**:
- 도전적이지만 달성 가능 (60~70% 달성이 정상)
- 팀이 왜 중요한지 이해할 수 있음
- 단일 분기(3개월) 내 진행 가능

**좋은 Key Result 조건**:
- 숫자로 측정 가능 (X에서 Y로)
- 팀이 직접 통제 가능 (외부 요인 의존 최소화)
- 출력(Output)이 아닌 결과(Outcome) 중심

**예시**:
```
O: 사용자가 우리 서비스 없이는 재고 관리를 상상할 수 없게 한다
KR1: MAU 10,000명 → 50,000명 달성
KR2: D30 리텐션 25% → 45% 달성
KR3: NPS 점수 20점 → 45점 달성
KR4: 유료 전환율 3% → 8% 달성
```

**피해야 할 패턴**:
- Task를 KR로 착각 ("앱 출시한다" → X)
- 100% 달성이 보장된 KR ("현재 유지한다" → X)
- 측정 방법이 불명확한 KR
