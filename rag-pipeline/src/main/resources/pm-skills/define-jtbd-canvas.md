# Jobs To Be Done (JTBD) 캔버스

**목적**: 사용자가 제품을 "고용"하는 근본적인 동기를 파악하여 진짜 경쟁자와 차별화 전략을 수립한다.

**JTBD 핵심 공식**:
"[상황]에서 [동기]를 이루기 위해 [장애물]에도 불구하고 [행동]을 한다."

**Job 유형**:
1. **기능적 Job**: 실제로 달성하고 싶은 과업 (예: "재고를 정확히 파악하고 싶다")
2. **감정적 Job**: 느끼고 싶은 감정 (예: "재고 때문에 걱정하지 않고 싶다")
3. **사회적 Job**: 타인에게 보이고 싶은 모습 (예: "체계적인 사업자로 보이고 싶다")

**경쟁 분석 활용**:
- 같은 Job을 해결하는 모든 솔루션이 경쟁자
- 예: "시간 때우기" Job → 유튜브, 인스타그램, 넷플릭스가 모두 경쟁자
- "더 나은 기존 방식"도 경쟁자로 포함

**JTBD 인터뷰 핵심 질문**:
- "마지막으로 [행동]을 했을 때 어떤 상황이었나요?"
- "그 전에는 어떻게 해결했나요?"
- "처음 [제품]을 사용하기로 결심했을 때를 기억하세요?"

**출력**: 주요 Job 3가지 + 각 Job에 대한 현재 대안 + 불만족 포인트
