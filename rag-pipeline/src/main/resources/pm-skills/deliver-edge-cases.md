# 엣지 케이스 식별 (Edge Cases)

**목적**: 예외적인 사용 상황을 사전에 정의하여 안정적인 서비스를 보장한다.

**엣지 케이스 카테고리**:
1. **입력값 경계**: 빈값, 최대값, 특수문자, 한글/영문 혼합, 이모지
2. **상태 전환**: 동시 요청, 중복 클릭, 네트워크 끊김 중 작업
3. **권한/접근**: 비로그인 접근, 권한 없는 리소스, 만료된 세션
4. **데이터 정합성**: 0개 데이터, 10만개 이상 데이터, 삭제된 연관 데이터 참조
5. **외부 의존성 실패**: 결제 API 오류, 이메일 발송 실패, 파일 업로드 실패
6. **시간 관련**: 자정 처리, 타임존 차이, 만료 직전/직후 상태

**엣지 케이스 발굴 질문**:
- "이 기능이 절대 사용되면 안 되는 상황은?"
- "가장 많이 사용될 때와 가장 적게 사용될 때의 차이는?"
- "사용자가 예상치 못한 방식으로 사용한다면?"
- "외부 시스템이 응답하지 않으면?"

**문서화 형식**:
```
케이스: [설명]
트리거: [발생 조건]
현재 동작: [현재 어떻게 처리되는가]
기대 동작: [어떻게 처리해야 하는가]
우선순위: 높음/중간/낮음
```
