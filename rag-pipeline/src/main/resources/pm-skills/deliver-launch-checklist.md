# 출시 체크리스트 (Launch Checklist)

**목적**: 제품 출시 전 모든 준비 사항을 체계적으로 검증하여 실패 리스크를 최소화한다.

**출시 전 (T-4주)**:
- [ ] MVP 범위 최종 확정 및 팀 공유
- [ ] 법적 검토 완료 (개인정보처리방침, 이용약관)
- [ ] 결제 시스템 테스트 (실제 결제 포함)
- [ ] 보안 취약점 스캔 완료
- [ ] 성능 부하 테스트 (예상 트래픽 3배 기준)

**출시 전 (T-1주)**:
- [ ] 베타 사용자 피드백 반영 완료
- [ ] CS 대응 매뉴얼 및 FAQ 준비
- [ ] 모니터링·알림 시스템 구축 (Sentry, Datadog 등)
- [ ] 롤백 계획 수립 (장애 시 복구 절차)
- [ ] 마케팅 채널 준비 (SNS, 이메일, PR)

**출시 당일**:
- [ ] 트래픽 모니터링 실시간 대응 체계
- [ ] 팀 전체 대기 (핫픽스 배포 준비)
- [ ] 사용자 유입 경로별 전환율 추적
- [ ] 첫 24시간 지표 리포트 계획

**출시 후 (T+1주)**:
- [ ] 핵심 지표(가입·전환·리텐션) 분석
- [ ] 사용자 인터뷰 5건 이상 진행
- [ ] 버그 리포트 우선순위화
- [ ] 다음 이터레이션 계획 수립
