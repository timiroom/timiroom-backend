# 기회 트리 (Opportunity Solution Tree)

**목적**: 비즈니스 목표에서 출발하여 기회 → 솔루션 → 실험으로 이어지는 구조적 사고를 유도한다.

**트리 구조**:
```
비즈니스 목표 (Desired Outcome)
  └─ 기회 1 (Opportunity — 충족되지 않은 니즈)
       ├─ 솔루션 1-A (Solution)
       │    └─ 실험 1-A-1 (Experiment)
       └─ 솔루션 1-B
  └─ 기회 2
       └─ 솔루션 2-A
```

**각 레이어 정의**:
1. **Desired Outcome**: 달성하고 싶은 비즈니스 결과 (1개, OKR의 KR과 연결)
2. **Opportunity**: 사용자의 충족되지 않은 니즈 또는 페인포인트
3. **Solution**: 기회를 해결하는 구체적인 제품 아이디어
4. **Experiment**: 솔루션 가설을 최소 비용으로 검증하는 방법

**기회 발굴 방법**:
- 사용자 인터뷰에서 "불편한 점" 추출
- 이탈 분석 (왜 떠났는가?)
- 지원 티켓 분류
- 세션 녹화 분석

**우선순위화 기준**:
- 이 기회가 얼마나 많은 사용자에게 영향을 미치는가?
- 이 기회가 얼마나 자주 발생하는가?
- 이 기회가 우리 목표와 얼마나 관련 있는가?
- 해결 가능성은 높은가?
