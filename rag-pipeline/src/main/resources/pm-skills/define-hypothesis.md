# 가설 설정 및 검증 (Hypothesis)

**목적**: 불확실한 가정을 명시적 가설로 표현하고 데이터로 검증한다.

**가설 작성 형식**:
"우리는 [타겟 사용자]가 [솔루션]을 제공받으면 [측정 가능한 결과]가 발생할 것이라고 믿는다. 이는 [근거]에 기반한다."

**가설 유형**:
1. **고객 가설**: "이런 사람들이 이 문제를 갖고 있다"
2. **문제 가설**: "이것이 그들의 진짜 문제다"
3. **솔루션 가설**: "우리 솔루션이 문제를 해결한다"
4. **비즈니스 가설**: "이 가격에 이만큼 팔린다"

**검증 우선순위** (리스크 × 불확실성):
- 높음: 즉시 검증 (MVP 또는 랜딩페이지 실험)
- 중간: 다음 스프린트 내 검증
- 낮음: 데이터 수집 후 검증

**최소 검증 방법**:
- 랜딩페이지 + 사전 예약 (Concierge MVP)
- 5명 심층 인터뷰
- A/B 테스트 (기능이 있는 경우)
- 유료 광고 전환율 테스트

**검증 완료 기준**:
- 샘플 수 명시 (N=?)
- 성공 기준 수치 명시 (전환율 X% 이상)
- 검증 기간 명시
