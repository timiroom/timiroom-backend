# 사용자 페르소나 (User Persona)

**목적**: 타겟 사용자를 구체적인 인물로 표현하여 의사결정 기준을 통일한다.

**페르소나 구성 요소**:
1. **기본 정보**: 이름(실제 느낌), 나이, 직업, 회사 규모, 거주지
2. **기술 수준**: 낮음/중간/높음 + 주로 사용하는 기기
3. **목표(Goal)**: 이 서비스를 통해 달성하고 싶은 것 (구체적 상황 포함, 2문장 이상)
4. **페인포인트**: 현재 어떻게 해결하고 있는지 포함 (2문장 이상)
5. **사용 패턴**: 접속 빈도, 주요 사용 시간대, 디바이스 (2문장 이상)
6. **인용구(Quote)**: 이 사용자가 실제로 할 법한 말

**작성 규칙**:
- 반드시 3명 작성 (2명 이하면 재작성)
- 연령대·직업·기술수준이 서로 달라야 함
- 실제 존재할 법한 구체적 인물로 작성
- "30대 직장인" 같은 추상적 표현 금지

**페르소나 검증**:
- 이 사람이 실제로 우리 서비스에 돈을 낼 것인가?
- 이 사람의 문제가 충분히 절박한가?
- 우리 팀이 이 사람을 위해 의사결정할 수 있는가?
