# 경쟁사 분석 (Competitive Analysis)

**목적**: 시장 내 경쟁 구도를 파악하고 차별화 포인트를 도출한다.

**분석 프레임워크**:
1. **경쟁사 선정**: 직접 경쟁사(동일 고객/문제 해결) 5개 이상. 한국 서비스 우선.
2. **데이터 수집**: 매출액·MAU·시장 점유율. 반드시 공신력 있는 출처 명시.
3. **기능 매트릭스**: 평가 기준 5개 설정 → 상/중/하 점수화.
4. **강점/약점**: 각 경쟁사별 구체적 사용자 불편 포함 2문장 이상.
5. **차별화 포인트**: "우리 서비스가 제공할 수 있는 고유 가치" 명시.

**출력 형식**:
```
경쟁사명 | 매출(출처) | 점유율 | 강점 | 약점 | 차별화 기회
```

**주의사항**:
- Shopify, Magento 등 글로벌 플랫폼 제외 — 한국 서비스만 분석
- 가상 서비스명(A사, B사) 사용 금지
- 경쟁사는 반드시 5개 이상 — 4개 이하면 재작성
